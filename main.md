| Pattern               | Used For                        | Example Problem                     |
| --------------------- | ------------------------------- | ----------------------------------- |
| Arrays                | Traversal, searching            | Maximum element                     |
| Two Pointers          | Pairing, reverse, sorted arrays | Efficient Janitor, Two Sum (sorted) |
| Sliding Window        | Subarrays, substrings           | Longest substring                   |
| HashMap / HashSet     | Fast lookup, frequency          | Two Sum, Duplicate elements         |
| Stack                 | Matching, undo                  | Balanced Brackets                   |
| Queue                 | BFS, scheduling                 | Print Binary Tree                   |
| Binary Search         | Sorted arrays                   | Search in sorted array              |
| Greedy                | Best local choice               | Efficient Janitor                   |
| Prefix Sum            | Range sum                       | Subarray Sum                        |
| Recursion             | Trees, DFS                      | Factorial                           |
| Backtracking          | Generate all possibilities      | N-Queens                            |
| Dynamic Programming   | Optimization                    | Fibonacci, Knapsack                 |
| Tree DFS/BFS          | Tree traversal                  | Level Order Traversal               |
| Graph BFS/DFS         | Networks                        | Number of Islands                   |
| Heap (Priority Queue) | Top K, scheduling               | K Largest Elements                  |
| Union Find            | Connected components            | Friend Circles                      |
